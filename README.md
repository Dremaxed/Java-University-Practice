# Java Fundamentals & OOP Practice ☕

This repository contains my practice code and exercises as part of my Software Engineering degree (Year 2).
Here I focus on learning the core concepts of Java and Object-Oriented Programming (OOP).

## 📂 Projects Overview

### 1. Box Project (OOP Basics) 📦
A fundamental exercise in building Classes and Objects.
* **Concepts:** Classes, Objects, Constructors, Encapsulation (Getters/Setters), `this` keyword, Method Overloading.
* **Key Feature:** Includes a logic to compare box sizes and protection against negative values.
* **Files:** `Box.java`, `BoxTester.java`

### 2. Password Generator 🔐
A utility program that generates random passwords based on user input.
* **Concepts:** Using Java built-in libraries (`java.util.Random`, `java.util.Scanner`, `String` class methods).
* **Functionality:** Takes a user's name, analyzes it (length, charAt), and appends a random number.
* **File:** `PasswordGenerator.java`

### 3. Grade Calculator 📊
Control flow practice.
* **Concepts:** `switch-case` statements with fall-through logic.
* **Functionality:** Converts numeric grades (1-10) into textual descriptions (Fail, Pass, Excellent, etc.).
* **File:** `MyclassTirgol.java`
